3. 人机校验规则

  1. 改名前预览：--mode dry-run 打印全部"原名→新名"，人确认后才 execute。
  2. 合法性校验：脚本自动拦截目标名重复、含 Windows 非法字符（\ / : * ? " < > |）。
  3. 前后对照日志：rename_log.csv 记录每个文件原名/新名/状态，可回溯。
  4. 人工抽检：随机抽 2–3 个核对新名是否符合编号规则与顺序。
  5. 证据保全：raw_data/ 原始样本不参与改名，永久保留供溯源。

4. 方法学与真实性说明

本实验遵循"不伪造数据"原则：

  • 人工耗时来自用户真实操作计时（45 s），非估算或编造；
  • AI 耗时来自代码对真实文件系统操作的实测（0.0095 s）；
  • 原始样本为复现用户描述的 Windows 真实默认命名场景，脚本运行于真实文件夹；
