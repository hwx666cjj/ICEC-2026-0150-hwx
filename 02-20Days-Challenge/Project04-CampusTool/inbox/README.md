# inbox/ —— 通知输入目录

把你在**班级群 / 课程群**里看到的原始通知，复制粘贴成本目录下的 `.txt` 文本文件，
脚本（`src/campus_digest.py`）每天运行时会读取这里全部 `.txt` 并提取结构化信息。

## 使用约定
- 一个 `.txt` = 一次粘贴的一批通知（多条之间用**空行**分隔即可被分别识别）。
- 文件名随意，例如 `2026-11-18_class.txt`、`高数群.txt`。
- 只放 `.txt`，其他格式不会被读取。
- 不想被重复聚合时，可手动移走已处理的文件，或运行 `python3 src/campus_digest.py --clear`。
