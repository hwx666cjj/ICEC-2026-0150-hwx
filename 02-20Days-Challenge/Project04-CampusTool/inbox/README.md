# inbox/ —— 通知输入目录

脚本 `src/campus_digest.py` 每晚 22:00 自动读取本目录下**全部 `.txt`**，从中提取日期、时间、标签，写入 `digest/` 和 `process_logs/`。

## 每天 10 秒操作（重要，决定日志质量）

1. 从班级群 / 课程群**复制一条今天真实出现的通知**（截止、作业、会议、调课都行，越真实越好）。
2. 在本目录右键 → 新建 → 文本文档，命名为 **`当天日期.txt`**，例如 `2026-11-16.txt`。
   - ⚠️ Windows 默认隐藏扩展名，务必确认文件名是 `2026-11-16.txt`，不要变成 `2026-11-16.txt.txt`。
3. 打开粘贴通知 → 保存。完成。当晚 22:00 脚本自动处理，你不用手动跑。

> 每天放**新的一条**即可，这样 7 天摘要内容各不相同——日志既连续又有变化，最能体现"真实持续使用"。
> 内容必须真实，不要编造；脚本只做提取，不会替你生成通知。

## 使用约定
- 一个 `.txt` = 一次粘贴的一批通知；多条之间用**空行**分隔，会被分别识别。
- 一条通知里的**多个日期/时间**都能提取（如 11/15、11/18 会全部列出）。
- 文件名随意，但建议带日期便于溯源，如 `2026-11-18_class.txt`。
- 只放 `.txt`，其他格式不会被读取。
- `day1.txt` 是 11/14 首次真实通知样本，保留作为起点记录，不用删。
- 想清空已处理文本可用 `python3 src/campus_digest.py --clear`（谨慎，会删掉所有 .txt）。

## 关于文件名"双后缀"
如果看到 `xxx.txt.txt`，说明 Windows 隐藏了扩展名。重命名时把整个 `xxx.txt.txt` 改成 `xxx.txt` 即可。
