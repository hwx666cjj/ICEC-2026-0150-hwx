# process_logs/ —— 运行遥测日志（大纲硬性交付：连续 ≥7 天）

每天脚本运行一次，向 `telemetry_YYYY-MM-DD.jsonl` **追加一行** JSON（每天一个文件，便于按日核对连续性）。

## 字段说明（脱敏，不含任何个人隐私）
| 字段 | 含义 |
|------|------|
| `ts` | 运行时间戳（ISO，秒级） |
| `inbox_files` | 当日读取的通知文件数 |
| `items_extracted` | 当日提取到的结构化条目数 |
| `elapsed_ms` | 本次运行耗时（毫秒，体现真实开销） |
| `errors` | 异常列表（无则空数组） |

## 示例一行
```json
{"ts":"2026-11-18T14:30:05","inbox_files":2,"items_extracted":5,"elapsed_ms":3.21,"errors":[]}
```

## 防摆拍说明
- 大纲要求"连续不少于 7 天的程序自动化运行日志，每日同步至 process_logs/"。
- 请用**系统定时任务**（Windows 任务计划程序 / macOS·Linux cron）每日自动调用脚本，
  而不是手动一次性补 7 个文件——面试会追问连续性，自动运行记录才站得住。
- 即使某天 inbox/ 为空，脚本也会写一条"空跑"记录，证明当日确实按调度执行。
